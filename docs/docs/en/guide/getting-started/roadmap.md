# Roadmap

Join the [project direction and roadmap discussion](https://github.com/react-native-motion-kit/react-native-text-motion/discussions/10) to propose features, compare priorities and discuss design decisions.

The library's priorities, scope and design decisions are maintained in the repository's [project context and roadmap](https://github.com/react-native-motion-kit/react-native-text-motion/blob/main/ROADMAP.md).

The current priority is verifying renderer performance and platform behavior on iOS and Android, then using that evidence to decide which additional APIs belong in the library.
